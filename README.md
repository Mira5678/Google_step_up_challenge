# Gemini Marketing Intelligence Platform

An interactive marketing analytics platform for evaluating Gemini campaigns and identifying opportunities to improve campaign efficiency, brand lift, and creative performance.

Note: This is part of Google Step Up Career Challenge - Power Google's Gemini Pro Breakthrough! With further improvement and expansion of the project by conducting more data analysis using Jupyter Notebook and creating a dashboard using Streamlit.

## The user journey:
Overview → Campaigns → Markets & Channels → Creatives → Recommendations → Budget Optimisation

## Setup

```bash
pip install -r requirements.txt
```

## Run

```bash
streamlit run app.py
